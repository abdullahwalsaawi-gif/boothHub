# بوث هب | Booth Hub 🎪
> **المنصة الذكية لإدارة المعارض وحجز البوثات في المملكة العربية السعودية**

---

## 📌 نبذة عن المشروع
**بوث هب (Booth Hub)** هي منصة ويب سحابية متكاملة تربط منظمي المعارض والمؤتمرات بالعارضين والمستأجرين في تجربة رقمية موحدة. تتيح المنصة استعراض المعارض القادمة، استكشاف المخططات الهندسية التفاعلية للصالات، حجز البوثات إلكترونياً مع تأكيد ذري يمنع الحجز المزدوج، بالإضافة إلى تقديم استشارات ذكية وتوصيات مدعومة بنماذج الذكاء الاصطناعي **Google Gemini**.

---

## 🛑 المشكلة التي تعالجها المنصة
1. **العمليات اليدوية والورقية**: اعتماد المنظمين على جداول Excel والمراسلات المشتتة عبر البريد والواتساب لإدارة البوثات وحجوزاتها.
2. **غياب الرؤية الحقيقية للموقع**: صعوبة اختيار العارض لموقع البوث المناسب بسبب عدم توفر مخططات تفاعلية حية توضح أبعاد البوث، تجهيزاته، وحالة توفره.
3. **خطر الحجز المزدوج (Double Booking)**: تزامن طلبات الحجز لنفس البوث مما يتسبب في إحراج للمنظمين وخسائر مالية.
4. **ضعف التوصية والتوجيه**: حيرة العارض في تحديد المعرض والبوث الأنسب لميزانيته ونشاطه التجاري.

---

## 💡 الحل المقترح
تقدم **بوث هب** حلاً رقمياً مركزياً يشمل:
* **مخططات تفاعلية حية (Interactive Floorplans)** تعتمد على SVG لعرض القاعات وتلوين البوثات تلقائياً حسب حالتها التشغيلية.
* **نظام حجز ذري في قاعدة البيانات (Atomic Transactions)** يمنع الحجز المزدوج نهائياً حتى في حالات الضغط المتزامن.
* **نظام مصادقة سريع وآمن** برقم الجوال ورمز التحقق (Phone OTP) وكلمات المرور.
* **مستشار ذكي مدعوم بـ Gemini AI** يجيب على استفسارات الزوار ويقدم توصيات بالبوثات الأنسب لكل نشاط استناداً حصراً لبيانات المنصة.
* **لوحات تحكم متخصصة** لكل من العارض والمنظم مع إحصائيات حية لنسب الإشغال والإيرادات.

## 👥 الفئات المستفيدة
1. **العارضون (Exhibitors)**:
   * استكشاف وتصفية المعارض حسب المدينة والتصنيف.
   * اختيار البوث عبر المخطط ومعرفة أبعاده وتجهيزاته وسعره.
   * إتمام طلب الحجز واستلام رقم مرجعي فوري ومتابعة حالة الطلب.
2. **منظمو المعارض (Organizers)**:
   * إنشاء ونشر المعارض الجديدة وإدارتها.
   * إدارة البوثات والمخططات الهندسية.
   * مراجعة وقبول أو رفض طلبات الحجز.
   * متابعة لوحة المؤشرات المالية ومعدلات الإشغال.
3. **الزوار والشركات العامة (Visitors)**:
   * تصفح المعارض المنشورة والاطلاع على مواعيدها وأماكن إقامتها.
   * استخدام المساعد الذكي للاستفسار عن فعاليات كل مدينة.

## 🚀 التقنيات المستخدمة (Tech Stack)
* **واجهة المستخدم والباك إند (Full-stack)**: Next.js 16 (App Router) مع React 19 و TypeScript.
* **التصميم والأنماط (Styling)**: Tailwind CSS v4، Lucide Icons، وتصميم متجاوب بالكامل للكمبيوتر والجوال مع دعم اللغة العربية (RTL).
* **قاعدة البيانات والمصادقة (BaaS)**: Supabase (PostgreSQL) مع حماية كاملة عبر Row Level Security (RLS).
* **الذكاء الاصطناعي (AI Integration)**: Google GenAI SDK (`@google/genai`) مع استدعاء آمن ومحمي من جانب الخادم (Server-side).
* **إدارة الجلسات السحابية**: `@supabase/ssr` مع Middleware نشط لحماية المسارات.

## ⚙️ طريقة التشغيل محلياً

### 1. استنساخ المستودع وتثبيت الاعتماديات:
```bash
git clone https://github.com/<USERNAME>/boothhub.git
cd boothhub
npm install
```

### 2. إعداد متغيرات البيئة:
قم بإنشاء ملف `.env.local` في جذر المشروع وأضف المتغيرات التالية (انظر `.env.example`):
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
GEMINI_API_KEY=your-gemini-api-key
```

### 3. إعداد قاعدة البيانات في Supabase:
انسخ محتوى الملف `supabase/migrations/001_initial_schema.sql` والصقه في قسم **SQL Editor** داخل لوحة تحكم Supabase واضغط على **Run**.

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🗄️ شرح قاعدة البيانات وسياسات الأمان (RLS)
تضم قاعدة البيانات 10 جداول رئيسية مصممة بأعلى معايير سلامة البيانات:
1. **`profiles`**: بيانات المستخدمين (عارض / منظم) مرتبطة بـ `auth.users`.
2. **`organizations`**: بيانات الجهات المنظمة الرسمية.
3. **`organization_members`**: جدول الصلاحيات الذي يربط المستخدم بالجهة (مالك، مدير، عضو).
4. **`exhibitions`**: المعارض المنشورة وحالاتها (مسودة، منشورة، ملغاة، مكتملة).
5. **`exhibition_plans`**: مخططات الصالات والقياسات الهندسية.
6. **`booths`**: البوثات وأرقامها، مساحاتها (م²)، أسعارها (ريال)، وتجهيزاتها ومواقعها الهندسية.
7. **`bookings`**: سجلات الحجز مع قيد جزئي ذري فريد `unique_active_booth_booking` يمنع الحجز المزدوج.
8. **`payments`**: سجلات عمليات الدفع والتحقق السحابي.
9. **`notifications`**: إشعارات المستخدمين داخل النظام.
10. **`audit_logs`**: سجل التدقيق للعمليات التشغيلية الحساسة.

## 🤖 شرح تكامل Gemini AI
تم دمج Google Gemini عبر الخادم حصراً (`src/lib/gemini.ts`) مع تطبيق قواعد صارمة:
* **مساعد بوث هب الذكي (`askBoothHubAssistant`)**: يتلقى استفسار المستخدم ويقوم الخادم بحقن سياق المعارض الحالية فقط، مانعاً النموذج من اختلاق أي أسعار أو معارض وهمية.
* **مستشار البوثات الأنسب (`recommendBoothsAI`)**: يحلل ميزانية العارض والمساحة والمدينة ونوع النشاط لترشيح أفضل المواقع المتاحة وتقديم نصيحة تسويقية واضحة.
* **مساعد المنظم**: يقترح صياغة احترافية لوصف الفعالية وشروط المشاركة.
